# Connected local web application

Owns the React/TypeScript user journey. Same-origin API is the authority; no
submission decision is made by client state. Career facts require explicit
verification and approval. Demo data is visibly fictional and opt-in. Builds
are served by FastAPI; no frontend development server is required for testing.
The Jobs view exposes explicit manual capture with an exact description, saved
reference/application links, preserved extra source fields and a visible
no-fetch explanation. Captured jobs use the existing canonical detail and
document-preparation path; their user-entered source identity is unverified.
